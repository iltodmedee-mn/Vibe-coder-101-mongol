# Vibe Coder 101 Mongol

Монгол vibe coder-уудад зориулсан Claude Code plugin. AI-тай ярьж апп хийдэг чамайг алхам алхмаар жинхэнэ бүтээгч болгоно: эхлээд сайн бодож, жижиг алхмаар хийж, тестээр шалгаж, кодоо цэвэр байлгана. Бүх skill Монгол хэлээр.

## Суулгах

Claude Code дотор эдгээр хоёр командыг ажиллуул:

```
/plugin marketplace add iltodmedee-mn/Vibe-coder-101-mongol
```

```
/plugin install vibe-coder-101-mongol@vibe-coder-101-mongol
```

Дараа нь repo бүртээ нэг удаа `/tohiruul`-ийг ажиллуул. Issue-гээ хаана хөтлөх, ямар label хэрэглэх, баримтаа хаана хадгалахыг асууж тохируулна.

Аль skill-ийг хэзээ ашиглахаа мэдэхгүй байвал `/zuvlu` гэж асуу.

Эдгээрийг agent ажлын явцад өөрөө сонгож хэрэглэнэ. Чи бас нэрээр нь дуудаж болно.

| `sudal` | Асуултыг найдвартай эх сурвалжаас судалж, файлд бичнэ |
