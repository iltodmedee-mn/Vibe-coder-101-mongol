# Skills

These are the 27 stable skills from [mattpocock/skills](https://github.com/mattpocock/skills) (plugin v1.3.2, commit `4ae2317`): the same set the `mattpocock-skills` Claude Code plugin ships. Each folder holds one skill. Claude Code loads them automatically from `.claude/skills/`.

They are copies, so they don't update themselves. To update, copy the newer skill folders over these from the upstream repo.

MIT licensed. See `LICENSE-mattpocock-skills`.

First step in a new repo: run `/setup-matt-pocock-skills`.
