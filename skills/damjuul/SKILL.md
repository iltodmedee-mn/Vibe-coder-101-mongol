Одоогийн яриаг хураангуйлсан handoff баримт бичиг бич, ингэснээр шинэ agent ажлыг үргэлжлүүлж чадна. Хэрэглэгчийн үйлдлийн системийн түр folder-т хадгал (`$TMPDIR`, байхгүй бол `/tmp`; Windows дээр `%TEMP%`), одоогийн workspace-д биш.

Зорилго, юу ажилласан (яаж мэдсэн), юу ажиллаагүй ба яагаад (дараагийн agent дахин оролдохгүйн тулд), дараагийн яг нэг алхмыг бич.

Баримт бичигт "санал болгох skill-үүд" хэсэг оруулж, дараагийн agent аль skill-үүдийг Skill tool-оор дуудах ёстойг нэрлэ.

Бусад artifact-д (spec, төлөвлөгөө, ADR, issue, commit, diff) аль хэдийн бичигдсэн зүйлийг давтаж бичихгүй. Оронд нь зам эсвэл URL-аар нь иш тат.

API key, нууц үг, хувь хүнийг таних мэдээлэл зэрэг нууц мэдээллийг хас.

Хэрэглэгч argument өгсөн бол түүнийг дараагийн session юунд анхаарах тухай тайлбар гэж үзээд, баримт бичгээ түүнд тааруул.

Эцэст нь файлын замыг хэрэглэгчид хэл.
