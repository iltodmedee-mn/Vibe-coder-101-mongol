# Triage Labels

Skill-үүд ангиллын (triage) таван үндсэн үүргээр ярьдаг. Энэ файл тэдгээр үүргийг энэ repo-гийн issue tracker дээрх бодит label-ийн нэр рүү харгалзуулна.

| Skill-ийн хэрэглэдэг нэр | Манай tracker дээрх label | Утга                                          |
| ------------------------ | ------------------------- | --------------------------------------------- |
| `needs-triage`           | `needs-triage`            | Maintainer энэ issue-г үнэлэх хэрэгтэй        |
| `needs-info`             | `needs-info`              | Мэдээлсэн хүнээс нэмэлт мэдээлэл хүлээж байна |
| `ready-for-agent`        | `ready-for-agent`         | Бүрэн тодорхойлогдсон, AFK agent-д бэлэн      |
| `ready-for-human`        | `ready-for-human`         | Хүн хэрэгжүүлэх шаардлагатай                  |
| `wontfix`                | `wontfix`                 | Хийгдэхгүй                                    |

Skill үүрэг дурдвал (жишээ нь "AFK-д бэлэн гэсэн triage label тавь"), энэ хүснэгтээс харгалзах label-ийн нэрийг хэрэглэ.

"Манай tracker дээрх label" баганыг өөрийнхөө бодитоор хэрэглэдэг нэрсээр зас.
