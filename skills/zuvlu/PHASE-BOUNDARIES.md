# Үе шатны зааг

**Үе шат** (phase) гэдэг нь session доторх ажлын хэсэг: ярилцлага, хэрэгжүүлэлт, QA. Тодорхойлолт нь санаатайгаар бүрхэг: *"за, үүнийг дуусгалаа"* гэж бодох үед үе шат дуусна.

**Үе шатны зааг** бол хоёр үе шатны хоорондох завсар бөгөөд энэ шийдвэр зөвхөн тэнд л хамаарна. Үе шатны дундуур гаргах шийдвэр байхгүй: үргэлжлүүл, эсвэл үлдсэн ажлыг subagent-уудад хуваа. Үе шатны дундуур compact хийвэл agent ажлын утсаа алддаг.

## Таван сонголт

| Сонголт         | Юу хийдэг                                                          |
| --------------- | ------------------------------------------------------------------ |
| **Үргэлжлүүл**  | Session-дээ үлдэнэ. Context огт солигдохгүй.                        |
| **`/clear`**    | Context window-ийг хоосолж, тэгээс эхэлнэ.                          |
| **`/damjuul`**  | Зөөж болох markdown файл бичиж, түүгээр хаана ч session эхлүүлнэ.   |
| **Subagent**    | Даалгаврыг өөрийн context window руу илгээж, тайлан буцааж авна.    |
| **`/compact`**  | Энэ context-ийг шахаж, хураангуйгаар нь шинэ session эхлүүлнэ.      |

## Мод

Зааг дээр дээрээс доош яв. Эхний **тийм** ялна.

**1. Энэ session-дээ үргэлжлүүлж чадах уу?** Хоёр зүйл хариултыг тийм болгоно: дараагийн үе шатанд энэ үе шат **анхдагч эх сурвалж** (primary source) болж хэрэгтэй, эсвэл дараагийн үе шат багтахуйц **smart zone** (model хурц сэтгэсээр байдаг context-ийн хэсэг, ~150k token) үлдсэн. Ярилцлага → хэрэгжүүлэлт бол стандарт тийм: хэрэгжүүлэлтэд үндэслэл нь хураангуйгаар биш, үгчлэн хэрэгтэй. Үргэлжлүүлэх нь юу ч зарцуулахгүй, юу ч алдахгүй тул өөр юу ч хийхээсээ өмнө үргэлжлүүлж болохгүй гэдгийг нь батал.

**2. Context нь дараагийн ажилд хамааралгүй юу?** Энэ session-ий бүх зүйл (судалгаа, шийдвэр, мухардал) хаягдаж болох уу? Тийм бол **`/clear`**. Самбар дээрх хамгийн хямд нүүдэл: цаг зарцуулахгүй, window-ийг бүтнээр нь буцааж өгнө. `/clear` бас эцсийнх биш: хуучин session-ийг дахин үргэлжлүүлж (resume) болно.

Үүнийг буруу шийдэх зардал нэг чиглэлтэй. *Хамааралтай* context-ийг clear хийвэл бүтээсэн зүйлийнхээ **яагаад**-ыг алдана, diff-ийг хичнээн дахин уншсан ч буцааж авч чадахгүй.

**3. Дамжуулах хэрэгтэй юу?** `/damjuul` явцуу. Зөвхөн дараах үед хэрэгтэй:

- **шинэ harness** руу солих (Claude → Codex),
- **шинэ folder** эсвэл repo руу шилжих,
- ажлыг **хамт ажиллагч** руу илгээх,
- эсвэл **үе шатны дундуур** олсон хажуугийн ажлыг одоогийн ажлаа замаас нь гаргалгүй салгах.

Энэ жагсаалт л бүх нөхцөл. `/damjuul`-ийн өгөх зүйл бол **зөөвөрлөх чадвар**: аялдаг файл. Юу ч аялахгүй бол хэрэггүй.

**4. Даалгаврыг AFK хийж болох уу?** Чамайг компьютерийн дэргэд байхгүй (AFK), жолоодлогогүй ажиллахуйц нарийн хүрээтэй юу? Тэгвэл **subagent** руу илгээж, энэ session-д хүрэлгүй үлдээ. Автомат хяналт бол стандарт жишээ: agent diff-ийг уншаад тайлагнана, тэр үед чи хэрэггүй.

**5. Бусад тохиолдолд `/compact`.** Хамааралтай context, ижил harness, ижил folder, бас чи давталтад оролцох хэрэгтэй: мод энд буудаг, бас ихэвчлэн энд буудаг. Заавар дамжуул (`/compact одоо энэ хэсгийг QA хийнэ`), ингэснээр хураангуй дараагийн үе шатанд хэрэгтэйг хадгална.

`/compact` бол **default, гэхдээ эхний сонголт биш**. Дээрх дөрвөн асуулт бүгд илүү хямд эсвэл илүү оновчтой тул хамгийн доор байрлана. Хүмүүс эндээс эхлэхэд гардаг алдаа бол хураангуйд хавтгайрсан шийдвэрийн талаар итгэлтэйгээр буруу ярьдаг шинэ session.

## Анхдагч ба хоёрдогч эх сурвалж

**Үргэлжлүүл**-ээс бусад нүүдэл бүр **анхдагч эх сурвалжийг** (primary source) **хоёрдогч эх сурвалж** (secondary source) болгодог: болсон байдлаараа session нь түүний хураангуйгаар солигдоно. Солилцоо үргэлж ижил хэлбэртэй:

| Эх сурвалж                             | Мэдээлэл     | Шуугиан | Хөдлөх зай |
| -------------------------------------- | ------------ | ------- | ---------- |
| Анхдагч (Үргэлжлүүл)                   | Бүтэн        | Их      | Бага       |
| Хоёрдогч (`/compact`, `/damjuul`)      | Алдагдалтай  | Бага    | Их         |

Тиймээс 1-р асуулт эхэнд байна. Үлдэх нь хэмнэхээсээ илүү үнэтэй үед л алдагдлын төлбөрийг төл.

## Эдгээр нь шүүлтийн шийдвэр

Асуултууд объектив биш: тус бүрд амт шингэсэн, ижил зааг хоёр өөр өдөр хоёр өөрөөр шийдэгдэж болно. Үнэ цэнэ нь тэдгээрийг **дарааллаар нь**, ажлын дунд биш зааг дээр асуухад оршино.
