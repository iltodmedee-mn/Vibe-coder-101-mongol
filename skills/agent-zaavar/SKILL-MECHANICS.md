# Skill-ийн механик

[`agent-zaavar`](SKILL.md)-ийн skill-д зориулсан салаа: баримт бичиг skill байхад юу өөрчлөгддөг (frontmatter, дуудах аргын сонголт, router skill). Бичих бусад бүх зүйл `SKILL.md` дахь ерөнхий лавлахад бий.

## Frontmatter

- Skill бол `<name>/SKILL.md` бүтэцтэй folder: Claude Code энэ файлыг skill-ийн орох цэг гэж үздэг. Folder-ийн нэр ба frontmatter-ийн `name` яг ижил, жижиг үсэг, зураастай (`aldaa-zas`).
- Frontmatter нь хоёр `---` мөрийн хоорондох хүчинтэй YAML. `:` эсвэл `"` агуулсан утгыг хашилтад хий.
- `description`-ий хэлбэр дуудах аргаас хамаарна (доор).

## Дуудлага

Хоёр сонголт, хоёр ачааллыг солилцоно:

- **Model-invoked** (agent өөрөө дууддаг) skill `description`-аа хадгалдаг тул agent түүнийг бие даан ажиллуулж, бусад skill түүнд хүрч чадна. Нэрийг нь бичиж ч дуудаж болно: model-invocation үргэлж хүний хүрэлтийг _багтаадаг_; description зөвхөн agent-ийн олж илрүүлэх боломжийг нэмдэг, хүнийхийг хэзээ ч хасдаггүй. Description бол skill-ийн дээд түвшний context pointer, үргэлж ачаалагдсан байх ёстой: олдохуйц байдлын төлөө байнгын context load. Агуулга нь бүхэлдээ лавлах model-invoked skill нь хуваалцсан лавлахын нэг гэр ч болно: өөр skill түүнийг дуудаж чадах тул хэд хэдэн skill-д хэрэгтэй лавлах нэг газар амьдарна. Механик: `disable-model-invocation`-ийг орхиж, өдөөх салаануудыг агуулсан, model-д хандсан description бич (`SKILL.md` дахь заагч бичих дүрэм бүрэн хамаарна).
- **User-invoked** (зөвхөн хүн нэрээр нь дууддаг) skill description-ийг agent-ийн хүрээнээс авна: зөвхөн нэрийг нь бичсэн хүн дуудаж чадна, өөр ямар ч skill чадахгүй. Context load тэг, гэхдээ cognitive load зарцуулна: байгааг нь санах ёстой индекс нь чи. Механик: `disable-model-invocation: true` тавина; `description` хүнд хандсан болно: нэг мөрт хураангуй, өдөөгчийн жагсаалтгүй.

Agent өөрөө skill-д хүрэх, эсвэл өөр skill хүрэх ёстой үед л model-invocation-ийг сонго. Зөвхөн гараар ажилладаг бол user-invoked болгож, context load төлөхгүй.

Хоёр user-invoked skill хоёулаа хэрэгтэй хуваалцсан лавлах аль алинд нь амьдарч чадахгүй: description байхгүй тул нэг нь нөгөөгөө ажиллуулж чадахгүй. Түүнийг skill системээс гадуурх энгийн файл руу гарга: ямар ч skill зааж болох гадаад лавлах.

## Дуудлагаар хуваах

Хуваалтын дуудлагын тайралт (дарааллын тайралт `SKILL.md`-д бий): өөрөө өдөөх ёстой тусдаа leading word (prompt-доо үнэхээр хэрэглэдэг өдөөгч үг) байгаа, эсвэл өөр skill түүнд хүрэх ёстой үед model-invoked skill-ийг салга. Шинэ, үргэлж ачаалагдсан description-ий context load-ыг төлөх тул тэр бие даасан хүрэлт үнэ цэнэтэй байх ёстой.

## Router skill

User-invoked skill-үүд санаж чадахаас чинь олон болоход хуримтлагдсан cognitive load-ыг **router skill** эмчилнэ: бусдыг нэрлэж, хэзээ алийг нь авахыг хэлдэг нэг user-invoked skill (жишээ нь `/zuvlu`), ингэснээр хүн олон биш нэг skill санана. Тэр зөвхөн сануулж чадна, хэзээ ч ажиллуулж чадахгүй: user-invoked skill-үүд description-гүй тул хүнээс өөр юу ч тэдэнд хүрэхгүй.

## Ажиллуулж шалга

Бичсэнийхээ дараа skill-ийг ажиллуулж үз: түүнийг өдөөх ёстой ажлыг шинэ session-д энгийн үгээр хэлээд, agent skill-д хүрч, алхмуудыг нь дагаж байгаа эсэхийг хар. Model-invoked skill-д хүрэхгүй байвал description-ий үг хэллэгийг хурцал. Мөн холбоос бүр байгаа файл руу заадаг, skill дотор API key, token, нууц үг үлдээгүй эсэхийг шалга.
