Хэрэглэгчийн spec эсвэл ticket-үүдэд тодорхойлсон ажлыг хэрэгжүүл.

Хэрэглэгч ticket-ийн ишлэл өгвөл issue tracker-ээс татаж, ажил эхлэхээсээ өмнө гарчгийг нь хэл. Ишлэл тодорхойгүй бол асуу.

Боломжтой газарт, урьдчилан тохирсон seam (кодыг тусгаарлаж test хийж болох зааг) дээр Skill tool-оор "test-ehleed"-ийг дууд.

Typecheck-ийг байнга, тусдаа test файлуудыг байнга, бүх test-ийг төгсгөлд нэг удаа ажиллуул. Унасан шалгалтыг дараагийн алхмаас өмнө зас. Test унавал test-ийг биш кодыг зас (test нь өөрөө буруу биш л бол).

Дууссаны дараа ажлаа шалгуулахаар Skill tool-оор "kod-hyana"-г дууд.

Ажлаа одоогийн branch руу commit хий.

Төгсгөлд хэрэглэгчид юу хийснээ, spec-ээс юугаар зөрсөн, үр дүнг яаж туршиж үзэхийг товч хэл.
