# GLOSSARY.md-ийн хэлбэр

## Бүтэц

```md
# {Context Name}

{One or two sentence description of what this context is and why it exists.}

## Нэр томъёо

**Захиалга**:
{A one or two sentence description of the term}
_Avoid_: Худалдан авалт, гүйлгээ

**Нэхэмжлэх**:
Хүргэлтийн дараа үйлчлүүлэгчид илгээдэг төлбөрийн хүсэлт.
_Avoid_: Тооцооны хуудас, төлбөрийн хүсэлт

**Үйлчлүүлэгч**:
Захиалга өгдөг хүн эсвэл байгууллага.
_Avoid_: Клиент, худалдан авагч, аккаунт
```

## Дүрэм

- **Байр сууриа тодорхой барь.** Нэг ойлголтод хэд хэдэн үг байвал хамгийн сайныг нь сонгоод, бусдыг нь `_Avoid_` дор жагсаа.
- **Тодорхойлолтыг товч байлга.** Дээд тал нь нэг хоёр өгүүлбэр. Юу хийдгийг нь биш, юу *болохыг* нь тодорхойл.
- **Зөвхөн энэ төслийн context-д өвөрмөц нэр томъёог оруул.** Програмчлалын ерөнхий ойлголт (timeout, алдааны төрөл, utility pattern) төсөлд хичнээн их хэрэглэгдсэн ч энд хамаарахгүй. Нэр томъёо нэмэхээсээ өмнө өөрөөсөө асуу: энэ нь энэ context-д өвөрмөц ойлголт уу, эсвэл програмчлалын ерөнхий ойлголт уу? Зөвхөн эхнийх нь орно.
- **Нэр томъёог дэд гарчгаар бүлэглэ**, байгалийн бүлгүүд үүсвэл. Бүх нэр томъёо нэг нэгдмэл хэсэгт хамаарвал энгийн жагсаалт болно.

## Нэг ба олон context-тэй repo

**Нэг context (ихэнх repo):** Repo-гийн root-д ганц `GLOSSARY.md`.

**Олон context:** Repo-гийн root-д байх `GLOSSARY-MAP.md` нь context-уудыг, тэдгээр хаана байрлахыг, хоорондоо хэрхэн холбогдохыг жагсаана:

```md
# Context-уудын map

## Context-ууд

- [Захиалга](./src/ordering/GLOSSARY.md): үйлчлүүлэгчийн захиалгыг хүлээн авч, хянана
- [Төлбөр](./src/billing/GLOSSARY.md): нэхэмжлэх үүсгэж, төлбөр боловсруулна
- [Хүргэлт](./src/fulfillment/GLOSSARY.md): агуулахаас бараа бэлтгэх, илгээхийг удирдана

## Холбоо

- **Захиалга → Хүргэлт**: Захиалга `OrderPlaced` event илгээнэ; Хүргэлт түүнийг хүлээн авч бараа бэлтгэж эхэлнэ
- **Хүргэлт → Төлбөр**: Хүргэлт `ShipmentDispatched` event илгээнэ; Төлбөр түүнийг хүлээн авч нэхэмжлэх үүсгэнэ
- **Захиалга ↔ Төлбөр**: `CustomerId` ба `Money` төрлийг хуваалцана
```

Аль бүтэц тохирохыг skill өөрөө тодорхойлно:

- `GLOSSARY-MAP.md` байвал context-уудыг олохын тулд түүнийг унш
- Зөвхөн root-д `GLOSSARY.md` байвал нэг context
- Аль нь ч байхгүй бол эхний нэр томъёо шийдэгдэх үед root-д `GLOSSARY.md`-г үүсгэ

Олон context байвал одоогийн сэдэв алинд нь хамаарахыг дүгнэж ол. Тодорхойгүй бол асуу.
