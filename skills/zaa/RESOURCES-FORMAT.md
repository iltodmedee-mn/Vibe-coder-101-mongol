# RESOURCES.md формат

`RESOURCES.md` бол энэ сэдвийн итгэлтэй эх сурвалжуудын шигшсэн жагсаалт. Тайлбарын мэдлэгийг сургалтын өгөгдлөөс таамаглахын оронд эндээс авна. Мэргэн ухаан энд жагсаасан нийгэмлэгүүдээс ирнэ.

## Бүтэц

```md
# {Сэдэв}: эх сурвалж

## Мэдлэг

- [Ном: _The Science and Practice of Strength Training_, Zatsiorsky & Kraemer](https://example.com)
  Хөтөлбөр зохиох, бие дасан зохицох тухай суурь ном. Хэзээ хэрэглэх: үечилсэн төлөвлөлт, сэргэлт, эрчмийн бүсийн тухай бүх зүйлд.
- [Нийтлэл: "How Much Should I Train?", Greg Nuckols (Stronger By Science)](https://example.com)
  Дасгалын хэмжээний гол хязгааруудын тухай нотолгоонд суурилсан тойм. Хэзээ хэрэглэх: булчингийн бүлэг бүрийн долоо хоногийн сетийн зорилтод.

## Мэргэн ухаан (Нийгэмлэг)

- [r/weightroom](https://reddit.com/r/weightroom)
  Чанартай мэдээлэлтэй, үндэслэлгүй зөвлөгөөг хянадаг subreddit. Хэзээ хэрэглэх: хөтөлбөрөө шүүмжлүүлэх, ахиц зогсонги үед шалтгааныг олох.
- Орон нутаг: {фитнес төвийн нэр}-ийн мягмар гарагийн хүчний анги
  Хэзээ хэрэглэх: хүндийн өргөлтөө дасгалжуулагчаар шууд засуулах.
```

## Дүрэм

- **Зөвхөн өндөр итгэлтэй.** Анхдагч эх сурвалж, хүлээн зөвшөөрөгдсөн мэргэжилтэн, хянан магадлагдсан бүтээл, сайн зохицуулалттай нийгэмлэгийг илүүд үз. Боловсрол мэт харагддаг маркетинг бол бүү оруул.
- **Бичлэг бүрт тайлбар нэм.** Зүгээр холбоос гурван сарын дараа ямар ч хэрэггүй. Нэг мөр нэм: юуг хамардаг, хэзээ хэрэглэх.
- **Мэдлэг / Мэргэн ухаан гэж бүлэглэ.** Энэ нь [SKILL.md](./SKILL.md)-ийн философитой таарна. Нэг эх сурвалж зөвхөн нэг бүлэгт байж болно.
- **Цоорхойг ил тод бич.** Зорилгод хэрэгтэй нэг чиглэлд сайн эх сурвалж байхгүй бол юу дутуу байгааг `## Цоорхой` хэсэгт жагсаа. Энэ нь ирээдүйн хайлтыг чиглүүлнэ.
- **Хатуу шүүж хас.** Буруу, гүехэн, эсвэл зорилгоос гадуур болж таарсан эх сурвалжийг булж үлдээлгүй, устга. Дунд зэргийн гучаас хурц тав нь дээр.
- **Нийгэмлэгийн талаарх хүслийг бич.** Хэрэглэгч нийгэмлэгт нэгдэхгүй гэж шийдсэн бол ирээдүйн session дахин санал болгохгүйн тулд энд тэмдэглэ.
