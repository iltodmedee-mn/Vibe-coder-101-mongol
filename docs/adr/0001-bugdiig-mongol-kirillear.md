# Бүх контентыг Монгол кириллээр бичнэ

Plugin-ий бүх контентыг, тэр дундаа agent уншдаг SKILL.md-ийг Монгол хэлээр, кирилл үсгээр бичнэ, учир нь Vibe coder-ууд англи хэл сул (Бодит нөхцөл). Англи заавар AI дээр илүү найдвартай ажилладаг, token бага зарцуулдаг, эх repo-той харьцуулахад хялбар гэсэн давуу талыг үүний төлөө орхив.

## Үл хамаарах зүйлс

- Техникийн нэр томъёо (`commit`, `branch`, `deploy`) англиар үлдэж, Нэр томъёоны толинд тайлбарлагдана.
- Skill, command-ын нэр техникийн шаардлагаар латин үсэгтэй тул чатын Галигаар бичигдэнэ (ө, ү → u; х → h; ж → j).
- Орчуулга үе шаттай явагдах тул орчуулагдаагүй хэсэг нь түр зуур англиар байна.
