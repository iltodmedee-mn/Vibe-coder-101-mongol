# Эх repo-уудын бүх skill, agent, command-ыг авна

Анхны зорилго нь хоёр Эх repo-г хуулж холих байсан тул тэдгээрийн бүх skill, agent, command-ыг нэг plugin-д авна. Ганцхан хүний тухай нээлттэй мэдээлэл цуглуулдаг skill-ийг (CC BY-SA лицензтэй, Ёс зүйтэй зөрчилдөж болзошгүй) авахгүй. Зөвхөн эхлэгчид хэрэгтэй 10–20 зүйлийг сонгож авах хувилбарыг орхив.

## Үр дагавар

- Орчуулах хэмжээ их (зөвхөн skill-үүд 100,000 орчим мөр) тул орчуулгыг гурван үе шаттай хийнэ.
- 400 орчим skill-ийн тайлбар context-ийг их зарцуулж, agent-д зөв skill-ээ сонгоход хэцүү байж магадгүй.
- Hook-уудаас зөвхөн ёс зүйг хамгаалдаг цөөн хэдийг авна. CLAUDE.md-ийн загвар (`examples/`), ажлын горимуудыг (`contexts/`) авч, MCP тохиргоо, ивээн тэтгэгчийн skill, бусад AI хэрэгслийн folder-уудыг авахгүй.
