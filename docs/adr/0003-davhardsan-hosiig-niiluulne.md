# Давхардсан хос бүрийг нэг Нийлмэл skill болгоно

Хоёр Эх repo-д ижил ажил хийдэг skill, agent, command бүрийг (жишээ нь `tdd` ба `tdd-workflow`) нэг Нийлмэл skill болгоно. Богино, жижиг алхмаар явдаг талын skill суурь болж, нөгөөгөөс нь Mindset-тэй зөрчилдөхгүй нэмэлтүүдийг авна. Хатуу тоон шаардлагуудыг (жишээ нь 80% test coverage) зөвлөмж болгоно. Хоёуланг нь тусад нь үлдээх хувилбарыг орхив.

## Үр дагавар

Нийлмэл skill аль ч Эх repo-гийн хуулбар биш болох тул эх repo шинэчлэгдэхэд өөрчлөлтийг гараар шилжүүлэх шаардлагатай.
