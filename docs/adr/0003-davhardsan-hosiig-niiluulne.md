# Давхардсан хос бүрийг нэг Нийлмэл skill болгоно

Эх repo-уудад ижил ажил хийдэг skill, agent, command бүрийг (жишээ нь Matt-ийн `tdd` ба ECC-ийн `tdd-workflow`) нэг Нийлмэл skill болгоно. Хоёуланг нь тусад нь үлдээх хувилбарыг орхив.
