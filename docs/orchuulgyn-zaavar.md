# Орчуулгын заавар

Эх repo-гийн англи контентыг энэ plugin руу оруулах бүрт мөрдөнө. Нэр томъёог [GLOSSARY.md](../GLOSSARY.md)-ээс харна.

## Хэл

- Монгол хэлээр, кирилл үсгээр бичнэ. Хэрэглэгчийг "чи" гэж, найз шиг дотно, урам өгсөн өнгөөр дуудна.
- Техникийн нэр томъёо латинаар, англиар үлдэнэ: `commit`, `branch`, `test`, `deploy`, `API`, `PR`, `issue`, `spec`, `ticket`, `module`, `interface`, `refactor`, `hook`, `subagent` гэх мэт.
- Онолын нэр томъёо (tracer bullet, deep module, seam, red-green-refactor, ADR) мөн англиар үлдэнэ. Анх гарахдаа хаалтанд нэг удаа Монголоор тайлбарлаж болно.
- Код, команд, файлын зам, placeholder, frontmatter-ийн түлхүүр (`name`, `description`, `disable-model-invocation`) хэвээрээ үлдэнэ.
- Утгыг яг дамжуулна. Mindset-ийн дагуу шууд, товч бичнэ.

## Нэр

- Skill, agent, command бүр Галиг нэртэй. Folder-ийн нэр ба frontmatter-ийн `name` ижил.
- Текст доторх бусад skill-ийн ишлэлийг шинэ Галиг нэрээр нь бичнэ.
- Галигийн дүрэм: ө, ү → u; х → h; ж → j; ц → ts; ш → sh; ч → ch; й → i; ы, ий → ii; я → ya; ё → yo; ю → yu; е → ye; э → e.

## Эх сурвалж

- Контентыг энэ plugin-ий өөрийнх шиг бичнэ. Эх repo, тэдгээрийн зохиогчийн нэр, холбоос нь зөвхөн [LICENSE](../LICENSE)-д байна.
- Эх repo-оос бусад гуравдагч этгээдийн бүтээлийг (ном, зохиогч) иш татсан бол хэвээр үлдээнэ.

## Нийлмэл skill

- Суурь skill-ийн бүтэц, өнгө аяс хэвээр үлдэнэ.
- Нөгөө эх repo-оос ижил ажил хийдэг, эхлэгчид үнэ цэнтэй, Mindset-тэй зөрчилдөхгүй хэсгийг л нэмнэ.
- Хатуу тоон шаардлагыг (жишээ нь "80% coverage") зөвлөмж болгоно. Тодорхой хэл/framework-д хамаарах хэсэг, эх repo-гийн өөрийн хэрэгслийн тухай хэсгийг авахгүй.
- Нийлмэл skill суурь skill-ээс 30%-иас илүү урт болохгүй.
